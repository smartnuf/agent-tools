# Agent Tools v0.2.1

This documentation-only patch corrects the README distributed as the PyPI
project description. Desired-state and Claude Code integration commands are
included in v0.2.0 and later; they do not require a repository checkout. The
v0.2.0 description incorrectly called them main-only pending a release.

Application behavior, command syntax, authorization requirements, dependency
constraints, native-provider mappings and platform support are unchanged from
v0.2.0. The package version changes to 0.2.1 so the corrected metadata can be
published without replacing the immutable v0.2.0 tag or distribution files.
Maintained platform and packaging guides also use version-qualified availability,
and the release procedure now requires inspection of surrounding availability
prose as well as automated example checks before tagging.

## Installation and upgrade

The commands below require v0.2.1 to have been published on PyPI. GitHub
prerelease creation precedes that separate publication step; use the
[PyPI version page](https://pypi.org/project/smartnuf-agent-tools/0.2.1/) to
confirm availability. Unpinned requests select the current stable PyPI version.

Install the core application through the supported PyPI/uv channel:

```sh
uv tool install --python 3.13 smartnuf-agent-tools
```

For an existing unpinned installation:

```sh
uv tool upgrade smartnuf-agent-tools
```

Change an exact pin explicitly when required:

```sh
uv tool install --python 3.13 --reinstall 'smartnuf-agent-tools==0.2.1'
```

The optional `documents` extra remains separately requested. Existing mutation,
provenance, verification and partial-result contracts are unchanged. See the
[installation guide](https://github.com/smartnuf/agent-tools/blob/main/README.md)
and [v0.2.0 release history](https://github.com/smartnuf/agent-tools/releases/tag/v0.2.0)
for the installed interface and platform limitations. No broader feature work
is included; a fresh human Intent decision follows completion of v0.2.
